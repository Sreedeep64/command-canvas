# Command Canvas

Command Canvas is a small terminal-practice dashboard built with plain HTML, CSS, and JavaScript. It includes a searchable command library, copy controls, a browser-saved progress checklist, and a safe command simulator.

## Run locally

```bash
npx --yes serve . -l 3000
```

Then open `http://localhost:3000`.

## Deploy a preview

```bash
vercel
```

The site has no build step or external runtime dependencies.
